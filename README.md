# Nexus Fitness

A responsive gym landing page built with HTML, CSS, JavaScript and Bootstrap 5. This is a front-end only project with no backend.

**Live demo:**https://nexusfitness-landing.netlify.app/

## Features

- Responsive layout that works on mobile, tablet and desktop
- Sticky navbar with a collapsible mobile menu
- Hero section with a live gym-floor occupancy panel that updates every few seconds
- Programs section: Strength, Conditioning, Mobility and Recovery
- Class schedule with day tabs and a Reserve button on each class
- Membership plans with a monthly / yearly price toggle
- Coaches and member testimonials sections
- Join form with Bootstrap validation
- Automatic light and dark mode that follows the device setting
- Accessible markup: labels, ARIA attributes, focus outlines and reduced-motion support

## Built with

- HTML5
- CSS3 (custom properties)
- JavaScript (vanilla)
- Bootstrap 5.3
- Google Fonts: Archivo and DM Sans

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Kirpa-Keswani/Nexus-Fitness
   ```
2. Open the folder in VS Code.
3. Start it with the Live Server extension, or open `index.html` in a browser.
